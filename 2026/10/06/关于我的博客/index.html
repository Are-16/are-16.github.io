关于我

你好，欢迎来到我的博客！👋

我是Are，一名 14 岁的初中生。平时喜欢折腾电脑、写点代码，也喜欢把学习和生活里的小发现记录下来。虽然还在慢慢学习，但我对编程、网络技术和开源世界充满好奇。

这个博客是什么？

这里是我用 Hexo + GitHub Pages 搭建的个人博客。

我希望把它当成一个属于自己的小角落，用来：

  • 记录学习笔记：编程、数学，以及任何我觉得有用的知识
  • 分享折腾经历：建站、配置、踩坑和解决问题
  • 写下生活随笔：成长中的想法、读书观影、日常灵感
  • 见证长期积累：让今天的点滴，变成未来的礼物

为什么想建博客？

一开始只是觉得“有一个自己的网站”很酷。
后来发现，写博客不只是展示，更是整理和思考。把学到的东西讲清楚，才算真正理解；把遇到的问题记下来，下次就不会再迷路。

关于技术

这个博客目前使用：

  • Hexo
  • GitHub Pages
  • Markdown
  • 主题：Butterfly

如果你也在用 Hexo，或者也在尝试搭建自己的博客，欢迎交流。
也许我们都会遇到很多 bug，但解决它们的过程本身就很有趣。

感谢你来到这里。
愿我们都能保持好奇，持续学习，慢慢变强。🚀

世界很大，代码很长，我还在路上。
